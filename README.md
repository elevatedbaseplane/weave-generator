# Weave Generator

Rebuild of the weave drafting workspace. The editable application lives in `dist/` and is also the deployed site. Those files are served directly. There is no separate source tree and no compile step.

The build recorded in the application status bar is `WF-WEAVE-FIELD-RADII-SVG-20260921`. The workspace header label remains `WF-R1D`.

## Local preview

```bash
npm run dev
```

or `node scripts/serve.mjs`.

This serves `dist/` at http://127.0.0.1:43828. Pass a port as the first argument to use another port:

```bash
node scripts/serve.mjs 43830
```

## Tests

```bash
npm test
```

This runs `node --test --test-isolation=none tests/*.test.mjs`.

To run one file:

```bash
node --test --test-isolation=none tests/foundation.test.mjs
```

## Static check

```bash
npm run check
```

This runs `node scripts/check.mjs`. It confirms `.openai/hosting.json` points at this rebuild and that the local assets referenced by `dist/index.html` exist. Module syntax is a separate check: `node --check dist/<file>.mjs`.

## Fixtures

```bash
node scripts/fixtures.mjs
```

This rewrites the three exchange samples in `fixtures/`.
